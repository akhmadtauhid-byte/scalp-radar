Preset IDR: harga dibaca dari Indodax (rupiah), sedangkan fee 0,22% per sisi dan slippage 0,05% dihitung sesuai Tokocrypto. Harga kedua bursa mirip tetapi tidak persis sama. Koin yang sepi di Indodax otomatis memakai data Binance. Jika ada promo "0 Fee" atau memakai order Limit (maker), ubah fee secara manual.
Data harga: API publik Binance (pasar spot). Fee Binance dan Tokocrypto berbeda, isi fee sesuai akun Anda agar hitungan bersih akurat. Token Telegram tersimpan hanya di browser perangkat ini.
